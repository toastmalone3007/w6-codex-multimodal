TASK 1 - Single Image Describer
==================================================

Prompt 1:

   installed. It suggested working step by step instead of building it all at once.

Prompt 2:

-> It found I only had llama3.2, which is text-only and cannot understand images.
   It explained I need a vision model and suggested llava or moondream.

Prompt 3:
llava (4.7 GB)
-> Downloaded llava and tested it with a sample picture. Learned the request
   format: POST http://localhost:11434/api/generate with
   { model, prompt, images: [base64], stream: false }, and the text comes back
   in the "response" field.

Prompt 4:
Desktop
-> Created the w6-codex-multimodal folder with an output folder, started a Git
   repo on the task1 branch.

Prompt 5:
(sent a screenshot of GitHub Desktop's "Create a new repository" dialog)
-> Learned I should use "Add local repository" instead, because the repo already
   existed, and that I can only publish after the first commit.

Prompt 6:

-> Explained the Summary (the commit message) and Description (optional) boxes
   in GitHub Desktop.

Prompt 7:
idk what to commit
-> The folder was still empty, so we built the first piece: the basic page
   (file input, preview box, Describe Image button, status line, result area).
   Commit: "Create initial web interface"

Prompt 8:
Done, next step
-> Checked Git and found the commit had NOT actually been made yet.

Prompt 9:
(sent a screenshot of GitHub Desktop with the commit ready)
-> Confirmed I was in the right repo and branch; told me to click Commit, then
   Publish. The "LF line endings" warning is harmless.

Prompt 10:

-> The repo was published to GitHub but was still empty - the commit had not
   gone through.

Prompt 11:
Yes, do it
-> The assistant made the first commit and pushed task1 to GitHub.

Prompt 12:
Add preview
-> Added the image preview. FileReader.readAsDataURL() turns the file into a
   data URL ("data:image/png;base64,...") that an <img> can show. The part after
   the comma is the base64 Ollama needs later.
   Commit: "Add image preview"

Prompt 13:
Works, commit it
-> Committed the preview. Added the click handler that sends the image to Ollama
   with fetch() and logs the reply in the console.
   Problem found: opening index.html by double-clicking (file://) makes Ollama
   reject the request with 403, because the browser sends Origin: null.
   Fix: serve the page from a local server.

Prompt 14:
VS Code Live Server
-> Installed Live Server so the page runs at http://127.0.0.1:5500, which Ollama
   allows.

Prompt 15:
its not giving the description
-> Troubleshooting: the request worked, but the code only printed the reply to
   the console. Added resultEl.textContent = data.response.trim() to show it on
   the page.
   Commit: "Connect application to Ollama"

Prompt 16:
Still not showing
-> Troubleshooting: Ollama's log showed my clicks were rejected with 413
   (Payload Too Large) because my photo was too big. Fixed by resizing the image
   on a <canvas> to max 1024px and sending it as a JPEG, and by checking
   response.ok so an error is shown instead of silently crashing.

Prompt 17:
Works now
-> Commit: "Display AI response"

Prompt 18:
Next step
-> Added feedback for all the cases in the brief: no image selected, processing
   (button disabled), success, and errors (Ollama not running = TypeError from
   fetch, or an error code from Ollama). Used try / catch / finally and a
   setStatus() helper with CSS colours.

Prompt 19:
one quick question, what's the deliverable for this assignment?
-> Got a checklist: code files, task1 and task2 branches, six screenshots in
   output/, prompt-history.txt, the ZIP, and the GitHub link.

Prompt 20:

-> Commit: "Add loading and error handling". Got instructions for the three
   Task 1 screenshots.

Prompt 21:

   "output", not "outputs".

Prompt 22:

Prompt 23:
